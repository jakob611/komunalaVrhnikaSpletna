# Guest product review · 2 November 2026

This ledger reviews the purpose and usefulness of every guest feature group in G01–G50, rather than treating passing render tests as proof of a good product. The [function inventory](GUEST-FUNCTIONS-2026-11-01.md) remains the detailed success/error/empty-state and evidence matrix. The current pass adds nine focused scenarios in `src/test/address-handoff.test.tsx`; all nine pass, as does TypeScript. These are component/integration checks, not claims of live browser or external-provider completion.

## Focused changes in this final pass

1. Removed address re-entry and redundant schedule submission from MyHome → complete schedule, including denied local storage.
2. Centralized safe browser address helpers; retained honest persistence/deletion feedback and added whitespace validation.
3. Clarified which address a displayed personal schedule belongs to while a replacement is being edited.
4. Added explicit saved-address reuse for subscription signup and service inquiries; kept subscription district selection and report location independent.
5. Expanded useful public search to notice text and custom-page content, with concise previews and bounded visible results.
6. Explained an unavailable future-calendar subscription while preserving direct provider actions and file fallback.

## Main-audit handoff: actual browser/live cases

- MyHome → full schedule with a remembered address and with browser storage blocked; verify no address in the navigation URL and no repeated submit step.
- Correct a saved address and confirm the previous address/schedule is clearly distinguished until saved.
- Reuse a saved subscription address, explicitly select the district, confirm the email and verify the capability-based management flow with an isolated recipient.
- Edit/restore a service execution address; report an issue elsewhere with written location and optional confirmed GPS/map point.
- Search text occurring only in a notice summary or custom-page body; follow the result to its notice anchor/page.
- Check direct Google/Apple/personal and work Outlook paths using the deployed origin, including an unconfirmed-route explanation; completing provider-account additions remains a separate external step.
- Retain the wider G01–G50 browser and live API/owner-data checks from the main matrix. This final product pass does not replace them.
